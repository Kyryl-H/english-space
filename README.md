# English Space

Безкоштовний двомовний (українська / англійська) освітній вебсайт для викладачів англійської мови Житомирського технологічного фахового коледжу КНУБА.

Сайт показує каталог інтерактивних завдань Wordwall та бібліотеку навчальних матеріалів. Контент ведуть викладачі в Google-таблиці, без редагування коду. Сайт працює як статичний на GitHub Pages: без сервера, бази даних і платних сервісів.

## Можливості

- Три сторінки: **Головна**, **Практика** (каталог завдань Wordwall), **Матеріали** (бібліотека).
- Пошук за назвою й описом та фільтри (категорія / тип, рівень), які працюють разом і без перезавантаження сторінки.
- Перемикач мови **UA / EN**: вибір зберігається в браузері.
- Дані з Google Sheets (CSV) з перевіркою записів: помилковий рядок пропускається і не ламає решту.
- Адаптивний дизайн (телефон, планшет, ноутбук), мобільне меню, видимий фокус клавіатури, підтримка `prefers-reduced-motion`.
- Безпечне відображення: тексти з таблиці вставляються лише як текст, посилання лише `https`.

## Технології

HTML5, CSS3, Vanilla JavaScript (без фреймворків і збирачів), Google Sheets (CSV) як джерело контенту, Git/GitHub, GitHub Pages. Єдина зовнішня залежність: шрифт **Inter** з Google Fonts.

## Запуск на комп'ютері

Браузер не дозволяє завантажувати дані, якщо відкрити `index.html` подвійним кліком (`file://`). Використовуйте локальний сервер:

1. Встановіть у VS Code розширення **Live Server**.
2. Відкрийте папку проєкту у VS Code.
3. Клацніть правою кнопкою на `index.html` → **Open with Live Server**.

Сайт відкриється за адресою на кшталт `http://127.0.0.1:5500/`. Зміни у файлах підхоплюються автоматично.

## Налаштування Google Sheets

Контент зберігається в **одній Google-таблиці з двома аркушами**.

### 1. Створення таблиці

1. Створіть Google-таблицю, наприклад «English Space — контент».
2. Перший аркуш назвіть `Wordwall_Cards`, другий `Materials` (назви аркушів для коду не важливі).
3. У **першому рядку** кожного аркуша введіть заголовки точно так, як нижче (регістр не важливий).

### 2. Аркуш `Wordwall_Cards` (сторінка «Практика»)

| Стовпець         | Обов'язковий | Опис                                                           |
| ---------------- | ------------ | -------------------------------------------------------------- |
| `ID`             | так          | Унікальний код запису: `1`, `2`, `g-001`…                      |
| `Title_UA`       | так\*        | Назва українською                                              |
| `Title_EN`       | ні           | Назва англійською (якщо порожньо, показується українська)      |
| `Category`       | так          | `Grammar`, `Vocabulary`, `Speaking`, `Listening` або `Reading` |
| `Level`          | так          | `A1`, `A2`, `B1` або `B2`                                      |
| `Description_UA` | ні           | Опис українською (до 600 символів)                             |
| `Description_EN` | ні           | Опис англійською                                               |
| `Wordwall_URL`   | так          | Посилання на завдання, що починається з `https://`             |
| `Image_URL`      | ні           | Посилання (`https://`) на зображення для картки                |
| `Published`      | так          | `TRUE` / `FALSE` (також `Так` / `Ні`, `1` / `0`)               |
| `Order`          | ні           | Число: менше значення означає вище в списку                    |

\* Потрібна хоча б одна назва (UA або EN). Стовпець `Title_UA` має бути в таблиці, але рядок може мати лише `Title_EN`.

### 3. Аркуш `Materials` (сторінка «Матеріали»)

| Стовпець         | Обов'язковий | Опис                                                                                       |
| ---------------- | ------------ | ------------------------------------------------------------------------------------------ |
| `ID`             | так          | Унікальний код запису                                                                      |
| `Title_UA`       | так\*        | Назва українською                                                                          |
| `Title_EN`       | ні           | Назва англійською                                                                          |
| `Type`           | так          | `Textbooks`, `Grammar`, `Dictionaries`, `Audio`, `Additional Materials` або `Useful Links` |
| `Level`          | ні           | `A1`–`B2`. Якщо порожньо, матеріал показується при будь-якому вибраному рівні              |
| `Description_UA` | ні           | Опис українською                                                                           |
| `Description_EN` | ні           | Опис англійською                                                                           |
| `URL`            | так          | Посилання `https://` (Google Drive чи інший ресурс)                                        |
| `Format`         | ні           | Короткий формат файлу: `PDF`, `MP3`, `DOCX` (до 20 символів)                               |
| `Published`      | так          | `TRUE` / `FALSE`                                                                           |
| `Order`          | ні           | Порядок показу                                                                             |

**Поради щодо зручності:**

- Для `Published` вставте прапорці: **Вставлення → Прапорець**.
- Для `Category`, `Level`, `Type` увімкніть випадаючі списки: **Дані → Перевірка даних**, щоб уникнути друкарських помилок.
- Рядки з `Published = FALSE` ігноруються повністю, тож чернетки можуть бути неповними.

### 4. Публікація кожного аркуша як CSV

Назви пунктів меню Google можуть трохи відрізнятися.

1. **Файл → Поділитися → Опублікувати в інтернеті**.
2. У списку замість «Весь документ» оберіть **конкретний аркуш** (`Wordwall_Cards`).
3. У другому списку оберіть формат **«Значення, розділені комами (.csv)»**.
4. Натисніть **Опублікувати** і скопіюйте посилання (воно має вигляд `https://docs.google.com/spreadsheets/d/e/…/pub?gid=…&single=true&output=csv`).
5. Повторіть для аркуша `Materials`.

### 5. Підключення до сайту

Відкрийте `js/config.js` і вставте посилання в `sources`:

```js
sources: {
  practice:  { url: 'ПОСИЛАННЯ_НА_CSV_АРКУША_Wordwall_Cards' },
  resources: { url: 'ПОСИЛАННЯ_НА_CSV_АРКУША_Materials' }
},
```

Адреси мають бути з `docs.google.com` і починатися з `https://`.

### 6. Права доступу й безпека

- Публікація в інтернеті **лише читання**. Редагувати таблицю можуть лише ті, кому ви надали доступ через «Поділитися» (додайте викладачів як редакторів за їхніми адресами; загальний доступ залиште «Обмежений»).
- Опублікований CSV доступний будь-кому, хто має посилання, і посилання лежать у відкритому репозиторії. Тому **не розміщуйте в таблиці персональні дані студентів, паролі, оцінки чи конфіденційну інформацію**: лише публічний контент.
- Зміни в таблиці з'являються на сайті не миттєво: Google оновлює опублікований CSV із затримкою (орієнтовно кілька хвилин).

## Як додати гру (завдання Wordwall)

1. Відкрийте таблицю, аркуш `Wordwall_Cards`.
2. Додайте новий рядок унизу.
3. Заповніть:
   - `ID`: унікальний (не такий, як в інших рядках);
   - `Title_UA` (і за бажанням `Title_EN`);
   - `Category` та `Level` зі списку допустимих значень;
   - `Wordwall_URL`: скопіюйте адресу гри з Wordwall (вона має починатися з `https://`);
   - `Published`: `TRUE`.
4. За бажанням додайте описи, `Image_URL` і `Order`.
5. Зачекайте кілька хвилин і оновіть сторінку «Практика» (Ctrl+F5).

Щоб тимчасово сховати гру, поставте `Published = FALSE`: видаляти рядок не потрібно.

## Як додати навчальний матеріал

Так само, як гру, але в аркуші `Materials`:

1. Додайте рядок: `ID`, `Title_UA`, `Type`, `URL`, `Published = TRUE`.
2. `Level` і `Format` вказуйте за потреби.
3. Для файлів на Google Drive скопіюйте посилання «Копіювати посилання» (доступ для тих, хто має посилання) і вставте в `URL`.

Сайт не завантажує чужі файли автоматично: кнопка лише відкриває посилання в новій вкладці.

## Тексти, переклади, контакти, викладачі

### Переклади інтерфейсу

Усі тексти інтерфейсу зберігаються в `js/i18n.js` у двох блоках: `ua` і `en`. Щоб змінити текст, знайдіть ключ (наприклад, `"home.h1"`) і поправте значення в обох блоках. У HTML тексти позначені атрибутом `data-i18n="ключ"`.

Перекладається лише інтерфейс. Вміст ігор Wordwall і файлів Google Drive не перекладається.

### Контакти в підвалі

Підвал повторюється у трьох файлах: `index.html`, `practice.html`, `resources.html` (блок `<footer class="site-footer">`). Телефони, email, сайт і соцмережі змінюйте **в усіх трьох файлах**. Адреса береться з ключа `footer.address` у `js/i18n.js`.

### Викладачі на головній сторінці

У `index.html` секція «Викладачі» містить три картки-заглушки. Замініть їх вашими даними.

Простий варіант (тексти показуються однаково в обох мовах):

```html
<article class="card card--teacher">
  <img
    class="teacher-photo teacher-photo--img"
    src="assets/images/foto-vykladacha.jpg"
    alt="Ім'я Прізвище По батькові"
    width="400"
    height="400"
    loading="lazy"
  />
  <h3>Ім'я Прізвище По батькові</h3>
  <p class="teacher-role">Посада</p>
  <p class="card-text"><strong>Спеціалізація:</strong> ваша спеціалізація.</p>
  <p class="card-text">Короткий опис викладача.</p>
</article>
```

Якщо посаду чи опис потрібно перекладати, додайте ключі в обидва блоки `js/i18n.js` (наприклад, `"teacher1.role"`) і додайте `data-i18n="teacher1.role"` до відповідного елемента.

## Фото й зображення

- Кладіть файли в `assets/images/`. Використовуйте `.jpg` або `.webp`, бажано до 200 КБ на зображення (зменште розмір перед додаванням: великі фото сповільнюють сайт).
- **Головне зображення (hero)** на головній: у `index.html` замініть блок `<div class="media-placeholder" …>…</div>` на:

```html
<img
  class="hero-image"
  src="assets/images/hero.jpg"
  alt="Короткий опис зображення"
  width="800"
  height="600"
/>
```

- **Фото викладача**: див. приклад вище (`teacher-photo--img`). Використовуйте квадратні або близькі до квадрата фото.
- **Зображення в картках завдань**: вкажіть `https://`-посилання в стовпці `Image_URL`. Якщо картинка не завантажиться, картка покаже лише текст.
- Для зображень завжди пишіть змістовний `alt` (опис того, що на фото).

## Публікація на GitHub Pages

GitHub Pages безкоштовний. Для безкоштовного акаунта GitHub репозиторій має бути **публічним**. Купувати домен не потрібно.

### Крок 1. Створіть репозиторій

1. Увійдіть на [github.com](https://github.com) (за потреби зареєструйтеся).
2. **New repository**. Назва може бути будь-якою, наприклад `english-space`.
3. Оберіть **Public**. Не додавайте README та інші файли (у проєкті вони вже є).
4. Створіть репозиторій і скопіюйте його адресу (`https://github.com/<ваш-логін>/<назва>.git`).

### Крок 2. Завантажте файли

У VS Code відкрийте термінал у папці проєкту (**Terminal → New Terminal**) і виконайте:

```bash
git init
git add .
git commit -m "English Space: перша версія"
git branch -M main
git remote add origin https://github.com/<ваш-логін>/<назва>.git
git push -u origin main
```

Git може попросити вхід у GitHub (відкриється вікно браузера).

_Без Git:_ на сторінці репозиторію оберіть **Add file → Upload files**, перетягніть вміст папки `english-site` (не саму папку) і натисніть **Commit changes**.

### Крок 3. Увімкніть GitHub Pages

1. У репозиторії: **Settings → Pages**.
2. У розділі **Build and deployment** оберіть **Source: Deploy from a branch**.
3. Оберіть гілку **main** і папку **/ (root)**, натисніть **Save**.
4. Зачекайте 1–3 хвилини й оновіть сторінку налаштувань: угорі з'явиться адреса сайту.

### Крок 4. Адреса сайту

Вона має вигляд `https://<ваш-логін>.github.io/<назва-репозиторію>/`. Усі посилання в проєкті відносні, тому він працює в підкаталозі репозиторію без додаткових налаштувань.

## Оновлення сайту

- **Контент (ігри й матеріали):** змінюйте лише в Google-таблиці. Код змінювати не потрібно.
- **Код, тексти, фото, контакти:** змініть файли, потім у терміналі:

```bash
git add .
git commit -m "Короткий опис змін"
git push
```

Сайт оновиться за 1–3 хвилини. Якщо ви не бачите змін, оновіть сторінку з очищенням кешу (**Ctrl+F5**).

## Перевірка після публікації

1. Усі три сторінки відкриваються, посилання в шапці й підвалі працюють.
2. Перемикач UA/EN працює на всіх сторінках, мова зберігається при переході між ними.
3. На «Практиці» та «Матеріалах» з'явились ваші записи (без заглушок і повідомлення про помилку).
4. Пошук і фільтри працюють окремо й разом, лічильник «Знайдено» оновлюється.
5. Кнопки «Відкрити» відкривають правильні сторінки в новій вкладці.
6. Змініть `Published` в одному рядку таблиці й переконайтеся, що через кілька хвилин сайт це відобразив.
7. Відкрийте сайт на телефоні: меню, фільтри, кнопки зручні, горизонтального прокручування немає.
8. У консолі браузера (F12) немає червоних помилок.
9. На головній замінено заглушки викладачів і зображення (якщо ви цього ще не зробили).

## Типові проблеми

Технічну причину збою видно в консолі браузера (F12 → Console): рядок `[Catalog:practice] Не вдалося завантажити дані` з кодом помилки.

| Що бачите на сайті                        | Код в консолі                                | Що робити                                                                                                                        |
| ----------------------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| «Каталог ще не налаштовано»               | `not-configured`                             | Вставте посилання на CSV у `js/config.js`                                                                                        |
| «Дані каталогу мають неправильний формат» | `not-csv`                                    | Замість CSV прийшла веб-сторінка: аркуш не опубліковано або вставлено не те посилання. Повторіть публікацію й оберіть формат CSV |
| те саме                                   | `schema`                                     | У першому рядку аркуша немає обов'язкових стовпців (їх список у `detail.missing`). Перевірте заголовки                           |
| те саме                                   | `bad-url`                                    | Посилання не з `docs.google.com` або не `https`                                                                                  |
| те саме                                   | `parse` / `too-large`                        | Пошкоджений або завеликий CSV: перевірте таблицю                                                                                 |
| «Сервер не відповів вчасно»               | `timeout`                                    | Повільний інтернет чи Google: спробуйте ще раз                                                                                   |
| «Не вдалося з'єднатися із сервером»       | `network`                                    | Немає інтернету або доступ заблоковано                                                                                           |
| «Сервер повернув помилку»                 | `http`                                       | Спробуйте пізніше; перевірте, що аркуш досі опубліковано                                                                         |

## Як додати категорію або рівень

**Рівень (наприклад, C1):**

1. У `js/config.js` додайте `'C1'` до `levels`.
2. У `practice.html` і `resources.html` у групі «Рівень» додайте кнопку за зразком інших:
   `<button class="chip" type="button" data-level="c1" aria-pressed="false">C1</button>`

**Категорія завдань:**

1. Додайте її до `practiceCategories` у `js/config.js`.
2. Додайте кнопку у `practice.html` (`data-category="назва малими літерами"`).
3. Додайте переклад із ключем `cat.назва` в обидва блоки `js/i18n.js`.

Тип матеріалу додається аналогічно (`materialTypes`, кнопка в `resources.html`, ключ у `js/i18n.js` і запис у `TYPE_KEYS` у `js/resources.js`).
