# English Space

Безкоштовний двомовний (українська / англійська) освітній вебсайт для викладачів і студентів англійської мови **Житомирського технологічного фахового коледжу КНУБА**.

**🌐 Сайт:** <https://english-space-zhtfk.vercel.app/>
**📦 Репозиторій:** <https://github.com/Kyryl-H/english-space>

Сайт містить каталог інтерактивних завдань Wordwall та бібліотеку навчальних матеріалів. Контент ведуть викладачі в Google-таблиці, без редагування коду. Сайт статичний: без сервера, бази даних і платних сервісів.

## Можливості

- Три сторінки: **Головна**, **Практика** (каталог завдань Wordwall), **Матеріали** (бібліотека).
- Пошук за назвою й описом та фільтри (категорія / тип, рівень), які працюють разом і без перезавантаження сторінки.
- Перемикач мови **UA / EN** із збереженням вибору в браузері.
- Дані з Google Sheets (CSV) з перевіркою записів: помилковий рядок пропускається й не ламає решту.
- Адаптивний дизайн (телефон, планшет, ноутбук), мобільне меню, видимий фокус клавіатури, підтримка `prefers-reduced-motion`.
- Безпечне відображення: тексти з таблиці вставляються лише як текст, посилання лише `https`.
- SEO: мета-теги, Open Graph, структуровані дані JSON-LD, `robots.txt`, `sitemap.xml`.

## Локальний запуск

Браузер не дозволяє завантажувати дані, якщо відкрити `index.html` подвійним кліком (`file://`). Потрібен локальний сервер:

1. Встановіть у VS Code розширення **Live Server**.
2. Відкрийте папку проєкту у VS Code.
3. Правою кнопкою на `index.html` → **Open with Live Server**.

Сайт відкриється за адресою на кшталт `http://127.0.0.1:5500/`. Зміни підхоплюються автоматично.

## Керування контентом у Google-таблиці

Увесь контент сторінок «Практика» та «Матеріали» зберігається в **одній Google-таблиці з двома аркушами**. Код змінювати не потрібно: додали або змінили рядок, і через кілька хвилин це видно на сайті.

### Ролі та доступ

| Роль             | Що робить                             | Як налаштувати                                   |
| ---------------- | ------------------------------------- | ------------------------------------------------ |
| Адміністратор    | Власник таблиці та репозиторію        | Створює таблицю й публікує аркуші                |
| Редактор         | Викладач, який додає ігри й матеріали | **Поділитися** → додати адресу → роль «Редактор» |
| Відвідувач сайту | Читає лише опублікований CSV          | Нічого не потрібно                               |

Загальний доступ до самої таблиці залиште **«Обмежений»**. Редагувати її зможуть лише додані користувачі.

### Аркуш `Wordwall_Cards` (сторінка «Практика»)

У **першому рядку** мають бути заголовки точно як нижче (регістр не важливий).

| Стовпець         | Обов'язковий | Опис                                                           |
| ---------------- | ------------ | -------------------------------------------------------------- |
| `ID`             | так          | Унікальний код запису: `1`, `2`, `g-001`…                      |
| `Title_UA`       | так\*        | Назва українською                                              |
| `Title_EN`       | ні           | Назва англійською (якщо порожньо, показується українська)      |
| `Category`       | так          | `Grammar`, `Vocabulary`, `Speaking`, `Listening` або `Reading` |
| `Level`          | так          | `A1`, `A2`, `B1` або `B2`                                      |
| `Description_UA` | ні           | Опис українською (до 600 символів)                             |
| `Description_EN` | ні           | Опис англійською                                               |
| `Wordwall_URL`   | так          | Посилання на завдання, що починається з `https://`             |
| `Image_URL`      | ні           | Посилання (`https://`) на зображення для картки                |
| `Published`      | так          | `TRUE` / `FALSE` (також `Так` / `Ні`, `1` / `0`)               |
| `Order`          | ні           | Число: менше значення означає вище в списку                    |

\* Потрібна хоча б одна назва (UA або EN). Стовпець `Title_UA` має бути в таблиці, але рядок може мати лише `Title_EN`.

### Аркуш `Materials` (сторінка «Матеріали»)

| Стовпець         | Обов'язковий | Опис                                                                                       |
| ---------------- | ------------ | ------------------------------------------------------------------------------------------ |
| `ID`             | так          | Унікальний код запису                                                                      |
| `Title_UA`       | так\*        | Назва українською                                                                          |
| `Title_EN`       | ні           | Назва англійською                                                                          |
| `Type`           | так          | `Textbooks`, `Grammar`, `Dictionaries`, `Audio`, `Additional Materials` або `Useful Links` |
| `Level`          | ні           | `A1`–`B2`. Якщо порожньо, матеріал показується при будь-якому вибраному рівні              |
| `Description_UA` | ні           | Опис українською                                                                           |
| `Description_EN` | ні           | Опис англійською                                                                           |
| `URL`            | так          | Посилання `https://` (Google Drive чи інший ресурс)                                        |
| `Format`         | ні           | Короткий формат файлу: `PDF`, `MP3`, `DOCX` (до 20 символів)                               |
| `Published`      | так          | `TRUE` / `FALSE`                                                                           |
| `Order`          | ні           | Порядок показу                                                                             |

### Налаштування таблиці для зручності редакторів

- **Прапорці для `Published`:** виділіть стовпець → **Вставлення → Прапорець**.
- **Випадаючі списки** для `Category`, `Level`, `Type`: **Дані → Перевірка даних → Випадаючий список**. Це виключає друкарські помилки.
- **Закріплений заголовок:** **Вигляд → Закріпити → 1 рядок**.
- **Захист заголовків:** **Дані → Захистити аркуші й діапазони** на першому рядку, щоб його випадково не змінили.

### Як додати гру (завдання Wordwall)

1. Відкрийте аркуш `Wordwall_Cards` і додайте новий рядок унизу.
2. Заповніть `ID` (унікальний), `Title_UA`, `Category`, `Level`, `Wordwall_URL` і `Published = TRUE`.
3. За бажанням додайте `Title_EN`, описи, `Image_URL` і `Order`.
4. Зачекайте кілька хвилин і оновіть сторінку «Практика» (Ctrl+F5).

Приклад рядка:

| ID    | Title_UA       | Title_EN       | Category | Level | Wordwall_URL                          | Published |
| ----- | -------------- | -------------- | -------- | ----- | ------------------------------------- | --------- |
| g-014 | Present Simple | Present Simple | Grammar  | A2    | `https://wordwall.net/resource/12345` | TRUE      |

### Як додати навчальний матеріал

Так само, але в аркуші `Materials`:

1. Додайте рядок: `ID`, `Title_UA`, `Type`, `URL`, `Published = TRUE`.
2. `Level` і `Format` вказуйте за потреби.
3. Для файлів на Google Drive: правою кнопкою на файл → **Надати доступ** → доступ «Усі, хто має посилання» (роль «Читач») → **Копіювати посилання** → вставте в `URL`.

Сайт не завантажує файли автоматично: кнопка лише відкриває посилання в новій вкладці.

### Як змінити, сховати або видалити запис

| Дія                        | Що зробити                                                             |
| -------------------------- | ---------------------------------------------------------------------- |
| Змінити назву чи опис      | Відредагувати клітинку                                                 |
| Тимчасово сховати          | `Published = FALSE` (рядок можна не видаляти й не дописувати до кінця) |
| Видалити назавжди          | Видалити рядок у таблиці                                               |
| Змінити порядок            | Змінити число в `Order` (менше число означає вище в списку)            |
| Замінити посилання на файл | Вставити нове посилання в `URL` / `Wordwall_URL`                       |

Рядки з `Published = FALSE` ігноруються повністю, тому чернетки можуть бути неповними.

### Правила, які бережуть сайт від помилок

1. `ID` не повторюється в межах аркуша.
2. Значення `Category`, `Level`, `Type` пишуться точно зі списку допустимих.
3. Усі посилання починаються з `https://` (без пробілів на початку й у кінці).
4. Не перейменовуйте й не видаляйте заголовки першого рядка.
5. Не додавайте порожніх рядків між записами заради «красивого вигляду»: використовуйте `Order`.
6. Рядок із помилкою сайт пропускає й не ламає решту: деталі видно в консолі браузера (F12), див. [Типові проблеми](#типові-проблеми).

### Публікація аркушів як CSV (одноразово)

Назви пунктів меню Google можуть трохи відрізнятися.

1. **Файл → Поділитися → Опублікувати в інтернеті**.
2. У першому списку замість «Весь документ» оберіть **конкретний аркуш** (`Wordwall_Cards`).
3. У другому списку оберіть формат **«Значення, розділені комами (.csv)»**.
4. Натисніть **Опублікувати** й скопіюйте посилання (вигляд `https://docs.google.com/spreadsheets/d/e/…/pub?gid=…&single=true&output=csv`).
5. Повторіть для аркуша `Materials`.

Після цього зміни в таблиці потрапляють у CSV автоматично (за замовчуванням увімкнено «Автоматично повторно публікувати після внесення змін»: перевірте це в **Файл → Поділитися → Опублікувати в інтернеті**, розділ «Опубліковані матеріали й налаштування»).

### Безпека й резервні копії

- Публікація в інтернеті **лише читання**. Опублікований CSV доступний будь-кому, хто має посилання, а посилання лежать у відкритому репозиторії. Тому **не розміщуйте в таблиці персональні дані студентів, паролі, оцінки чи конфіденційну інформацію**: лише публічний контент.
- Щоб припинити публікацію: **Файл → Поділитися → Опублікувати в інтернеті → Припинити публікацію**. Сайт тоді покаже повідомлення про помилку завантаження.
- Історія змін: **Файл → Історія версій**. Через неї можна відновити випадково видалений запис.
- Раз на семестр робіть копію таблиці: **Файл → Створити копію**.

## Підключення таблиці до сайту

Відкрийте `js/config.js` і вставте посилання на CSV:

```js
sources: {
  practice:  { url: 'ПОСИЛАННЯ_НА_CSV_АРКУША_Wordwall_Cards' },
  resources: { url: 'ПОСИЛАННЯ_НА_CSV_АРКУША_Materials' }
},
```

Адреси мають бути з `docs.google.com` і починатися з `https://`. Після зміни файлу виконайте `git push` (див. [Оновлення сайту](#оновлення-сайту)).

## Тексти, переклади, контакти, викладачі

### Переклади інтерфейсу

Усі тексти інтерфейсу зберігаються в `js/i18n.js` у двох блоках: `ua` і `en`. Щоб змінити текст, знайдіть ключ (наприклад, `"home.h1"`) і поправте значення в **обох** блоках. У HTML тексти позначені атрибутом `data-i18n="ключ"`.

Перекладається лише інтерфейс. Вміст ігор Wordwall і файлів Google Drive не перекладається.

### Контакти в підвалі

Підвал повторюється в трьох файлах: `index.html`, `practice.html`, `resources.html` (блок `<footer class="site-footer">`). Телефони, email, сайт і соцмережі змінюйте **в усіх трьох файлах**. Адреса береться з ключа `footer.address` у `js/i18n.js`.

### Викладачі на головній сторінці

У `index.html` секція «Викладачі» містить картки викладачів. Приклад картки:

```html
<article class="card card--teacher">
  <img
    class="teacher-photo teacher-photo--img"
    src="assets/images/Tetiana_Yuriivna.jpg"
    alt="Карплюк Тетяна Юріївна"
    data-i18n-attr="alt:teacher.karpliuk.name"
    loading="lazy"
  />
  <h3 data-i18n="teacher.karpliuk.name">Карплюк Тетяна Юріївна</h3>
  <p class="teacher-role" data-i18n="teacher.karpliuk.role">
    Викладач, спеціаліст першої категорії
  </p>
</article>
```

Щоб додати нового викладача:

1. Скопіюйте всю картку `<article>…</article>` і вставте поряд.
2. Змініть фото, `alt` і тексти.
3. Додайте ключі `teacher.<ім'я>.name` і `teacher.<ім'я>.role` в обидва блоки `js/i18n.js` (`ua` та `en`).
4. Для трьох карток поспіль сітка вже налаштована; для іншої кількості перевірте клас `card-grid--3` у `css/components.css`.

## Фото й зображення

- Кладіть файли в `assets/images/`. Використовуйте `.jpg` або `.webp`, бажано до 200 КБ на зображення: великі фото сповільнюють сайт.
- **Фото викладачів:** квадратні або близькі до квадрата (рекомендовано від 600×600 до 800×800). Сайт показує їх у квадратній рамці однаково на всіх екранах і обрізає по краях; обличчя лишаються в кадрі, бо фото вирівнюється по верхньому краю.
- **Головне зображення (hero):** замініть заглушку в `index.html` на:

```html
<img
  class="hero-image"
  src="assets/images/hero.jpg"
  alt="Короткий опис зображення"
  width="800"
  height="600"
/>
```

- **Зображення в картках завдань:** вкажіть `https://`-посилання в стовпці `Image_URL`. Якщо картинка не завантажиться, картка покаже лише текст.
- Для всіх зображень пишіть змістовний `alt`.

## Публікація на Vercel

Сайт розміщено на **Vercel** (безкоштовний план Hobby, для некомерційних проєктів). Репозиторій на GitHub підключено до Vercel, тому кожен `git push` у гілку `main` автоматично оновлює сайт.

### Перша публікація

1. Зареєструйтесь на [vercel.com](https://vercel.com) через акаунт GitHub.
2. **Add New → Project** і виберіть репозиторій `english-space` (**Import**).
3. Налаштування залиште такими:
   - **Application Preset:** `Other`
   - **Root Directory:** `./`
   - **Build and Output Settings** і **Environment Variables**: нічого не змінюйте (збирання не потрібне).
4. Натисніть **Deploy**. Через хвилину сайт буде доступний за адресою Vercel.

### Домен

Безкоштовна адреса має вигляд `<назва-проєкту>.vercel.app`. Щоб змінити її: **Project → Settings → Domains** → додайте нову адресу, а стару налаштуйте як **Redirect to Another Domain**. Поточна адреса: `english-space-zhtfk.vercel.app`.

Після зміни адреси потрібно оновити її в файлах (див. [SEO](#пошукова-оптимізація-seo)).

### Інші варіанти хостингу

Сайт статичний, тому підійде будь-який статичний хостинг: **GitHub Pages** (репозиторій має бути публічним; для безкоштовного акаунта GitHub приватний репозиторій не підходить), **Cloudflare Pages**, **Netlify**. Усі посилання в проєкті відносні, тому він працює й у підкаталозі.

## Оновлення сайту

- **Контент (ігри й матеріали):** змінюйте лише в Google-таблиці. Код змінювати не потрібно.
- **Код, тексти, фото, контакти:** змініть файли, потім у терміналі:

```bash
git add .
git commit -m "Короткий опис змін"
git push
```

Vercel оновить сайт приблизно за хвилину. Якщо змін не видно, оновіть сторінку з очищенням кешу (**Ctrl+F5**).

## Пошукова оптимізація (SEO)

### Що вже налаштовано

- У кожній сторінці унікальні `<title>`, `description`, `canonical` та Open Graph теги, `lang="uk"`.
- На головній додано структуровані дані JSON-LD (`WebSite`).
- У корені лежать `robots.txt` і `sitemap.xml` з адресами всіх трьох сторінок.
- Файл `google<код>.html` у корені підтверджує право власності на сайт у Google Search Console. **Не видаляйте його.**

### Якщо змінилася адреса сайту

Замініть стару адресу на нову (у VS Code: Ctrl+Shift+H, «замінити в усіх файлах») у:

- `index.html`, `practice.html`, `resources.html`: `canonical`, `og:url` та JSON-LD;
- `robots.txt` (рядок `Sitemap:`);
- `sitemap.xml`.

### Google Search Console

1. Відкрийте [search.google.com/search-console](https://search.google.com/search-console), **Додати ресурс → Префікс URL**, вставте адресу сайту з `https://` і слешем в кінці.
2. Підтвердіть власність: файлом (покладіть наданий файл у корінь проєкту) або мета-тегом у `<head>` головної сторінки, потім `git push` і **Підтвердити**.
3. У розділі **Sitemaps** додайте `sitemap.xml`.
4. У рядку **Inspect any URL** вставляйте адреси сторінок і натискайте **Request indexing**. Google обмежує кількість таких запитів на добу (для нового ресурсу їх мало): надсилайте по одній адресі на день.

### Нова сторінка

Додайте її в `sitemap.xml` ще одним блоком `<url>`, зробіть `git push` і запросіть індексацію в Search Console.

### Як пришвидшити появу в пошуку

- Додайте посилання на сайт на офіційному сайті коледжу `ztk.org.ua` і в соцмережах коледжу.
- Зберігайте адреси сторінок незмінними: нові адреси Google індексує заново.
- Перевірте появу в індексі запитом `site:english-space-zhtfk.vercel.app` у Google (зазвичай через кілька днів або тижнів).

## Перевірка після публікації

1. Усі три сторінки відкриваються, посилання в шапці й підвалі працюють.
2. Перемикач UA/EN працює на всіх сторінках, мова зберігається при переході.
3. На «Практиці» та «Матеріалах» з'явились ваші записи (без помилки завантаження).
4. Пошук і фільтри працюють окремо й разом, лічильник «Знайдено» оновлюється.
5. Кнопки «Відкрити» відкривають правильні сторінки в новій вкладці.
6. Змініть `Published` в одному рядку таблиці й переконайтеся, що через кілька хвилин сайт це відобразив.
7. Відкрийте сайт на телефоні: меню, фільтри, кнопки зручні, горизонтального прокручування немає, фото викладачів виглядають як на комп'ютері.
8. Відкриваються `/robots.txt` і `/sitemap.xml`.
9. У консолі браузера (F12) немає червоних помилок.

## Типові проблеми

Технічну причину збою видно в консолі браузера (F12 → Console): рядок `[Catalog:practice] Не вдалося завантажити дані` з кодом помилки.

| Що бачите на сайті                        | Код в консолі                                | Що робити                                                                                                                        |
| ----------------------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| «Каталог ще не налаштовано»               | `not-configured`                             | Вставте посилання на CSV у `js/config.js`                                                                                        |
| «Дані каталогу мають неправильний формат» | `not-csv`                                    | Замість CSV прийшла веб-сторінка: аркуш не опубліковано або вставлено не те посилання. Повторіть публікацію й оберіть формат CSV |
| те саме                                   | `schema`                                     | У першому рядку аркуша немає обов'язкових стовпців (список у `detail.missing`). Перевірте заголовки                              |
| те саме                                   | `bad-url`                                    | Посилання не з `docs.google.com` або не `https`                                                                                  |
| те саме                                   | `parse` / `too-large`                        | Пошкоджений або завеликий CSV: перевірте таблицю                                                                                 |
| «Сервер не відповів вчасно»               | `timeout`                                    | Повільний інтернет чи Google: спробуйте ще раз                                                                                   |
| «Не вдалося з'єднатися із сервером»       | `network`                                    | Немає інтернету або доступ заблоковано                                                                                           |
| «Сервер повернув помилку»                 | `http`                                       | Спробуйте пізніше; перевірте, що аркуш досі опубліковано                                                                         |
| Запису немає в списку                     | попередження `[Sheets] … проблемних записів` | Розгорніть попередження в консолі: там номер рядка й причина (некоректний URL, дубль ID, невідома категорія тощо)                |
| Зміни в таблиці не видно                  |                                              | Зачекайте кілька хвилин і натисніть Ctrl+F5                                                                                      |
| Зміни в коді не видно                     |                                              | Перевірте, що виконано `git push`, а у Vercel (вкладка **Deployments**) останній деплой має статус **Ready**                     |

Діагностика швидкості: додайте до адреси `?debug` (наприклад, `practice.html?debug`), і в консолі з'являться тривалість завантаження та перемальовування.

## Як додати категорію, рівень чи тип

**Рівень (наприклад, C1):**

1. У `js/config.js` додайте `'C1'` до `levels`.
2. У `practice.html` і `resources.html` у групі «Рівень» додайте кнопку за зразком інших:
   `<button class="chip" type="button" data-level="c1" aria-pressed="false">C1</button>`

**Категорія завдань:**

1. Додайте її до `practiceCategories` у `js/config.js`.
2. Додайте кнопку в `practice.html` (`data-category="назва малими літерами"`).
3. Додайте переклад із ключем `cat.назва` в обидва блоки `js/i18n.js`.

**Тип матеріалу:** аналогічно (`materialTypes`, кнопка в `resources.html`, ключ у `js/i18n.js` і запис у `TYPE_KEYS` у `js/resources.js`).

Не забудьте оновити випадаючі списки в Google-таблиці (**Дані → Перевірка даних**).

## Відомі обмеження

- **Затримка Google:** опублікований CSV оновлюється не миттєво.
- **Ігри Wordwall** лише відкриваються за посиланням у новій вкладці; вбудовування не передбачено.
- **Вміст ігор і файлів не перекладається:** перемикач змінює лише інтерфейс.
- **Викладачі, контакти й підвал** редагуються в HTML (підвал у трьох файлах).
- **Рівні, категорії й типи** є фіксованим списком (зміна описана вище).
- **Немає адміністративної панелі та входу:** контент редагується лише в Google-таблиці.
- **Картки каталогу** формуються JavaScript із таблиці, тому пошукові системи індексують їх гірше за статичний текст; для видимості сторінок у пошуку важливі опис і статичний текст на самих сторінках.
- **Шрифт Inter** завантажується з Google Fonts; без інтернету показується системний шрифт.
- **Локально сайт потрібно запускати через сервер** (Live Server), а не подвійним кліком.
- **Браузери:** сучасні версії Chrome, Edge, Firefox, Safari. Старі (наприклад, Internet Explorer) не підтримуються.
- Дані таблиці **публічні**: не зберігайте там конфіденційну інформацію.
